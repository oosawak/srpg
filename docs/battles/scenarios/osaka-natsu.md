# 大坂夏の陣・道明寺

## 基本情報

- **年月日**: 慶長20年5月6日（1615年）
- **場所**: 河内国 道明寺・小松山（地形はゲーム用の模式図・創作）
- **両軍と兵力**: 伊達軍（政宗・景綱・秀宗ら） 対 豊臣方（後藤基次・薄田兼相・木村重成ら）
- **勝利条件**: 後藤基次の撃破（敵全滅でも勝利）
- **敗北条件**: 伊達政宗の討ち死に、または制限ターン（10ターン）超過
- **該当章**: [『伊達の国』コラム「宇和島 ― 飛び地の番外編」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-col-uwajima)
- **開戦メッセージ**: 慶長20年5月・道明寺の戦い。朝霧の石川を押し渡り、小松山に布陣する後藤基次を破れ。

## 概況

大坂夏の陣の初戦となった河内・道明寺の合戦。濃い朝霧が立ちこめる中、豊臣方の猛将・後藤基次（又兵衛）は古墳の丘・小松山に陣取って後続の到着を待ったが、本隊の遅れにより孤立。伊達軍の先鋒と激突して壮絶な戦死を遂げた。政宗の本隊が道明寺方面の豊臣勢を打ち破ったことで、徳川方の大軍が大坂城へ一気に迫る流れが作られた。
