# 白石城と関ヶ原

## 基本情報

- **年月日**: 慶長5年7月（1600年）
- **場所**: 陸奥国・刈田郡 白石城（地形はゲーム用の模式図・創作）
- **両軍と兵力**: 伊達軍（徳川東軍方・旧臣も呼応） 対 上杉方・白石城守備隊（城主・甘粕景継不在）
- **勝利条件**: 上杉守備隊・本隊（大将）の撃破、または上杉守備隊の全滅
- **敗北条件**: 伊達政宗の討ち死に（または10ターン超過）
- **該当章**: [『伊達の国』第22章「南の門 ― 白石・角田・亘理」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-ch22-minami-no-mon)
- **開戦メッセージ**: 慶長5年7月・白石城攻め。奥州街道の南の門を奪還し、関ヶ原の年の足場を築け。

## 概況

慶長5年（1600年）、徳川家康の上杉討伐に呼応した伊達政宗は、城主・甘粕景継が不在であった上杉領の白石城を攻めた。片倉景綱らが前線に立ち、出奔していた伊達成実も留守政景と景綱の説得に応じてこの白石の陣で帰参。さらに1591年の移封で伊達郡に残った旧臣たちも伊達方として呼応し、のちの仙台「三百人町」へつながる働きを見せた。奪還した白石城は山形・福島二正面の足場となり、戦後は片倉景綱の居城となる（第3章「松川の戦い」・第11章「若林の足軽町」とも連動）。
