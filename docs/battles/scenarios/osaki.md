# 大崎合戦

## 基本情報

- **年月日**: 天正16年1月〜（1588年）
- **場所**: 陸奥国・志田郡・黒川郡方面（旧大崎領／地形はゲーム用の模式図・創作）
- **両軍と兵力**: 伊達勢（留守政景ら） 対 大崎勢・最上義光援軍 約5千（伝え）
- **勝利条件**: 留守政景が南端の離脱マス（伊達領方面）へ到達、または7ターン終了まで生存（敵全滅でも勝利）
- **敗北条件**: 留守政景の討ち死に
- **該当章**: [『伊達の国』第9章「迷い込む岩出山」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-ch09-iwadeyama)
- **開戦メッセージ**: 天正16年・大崎合戦。最上・大崎勢の包囲を凌ぎ、留守政景を南の退路へ導け。

## 概況

伊達政宗は大崎氏の内紛に乗じて大崎領へ兵を進めたが、大崎氏と縁の深い出羽山形の最上義光（政宗の伯父）が大崎方へ援軍を送り、戦局は一変する。厳冬の泥濘と雪の中、伊達勢を率いた政宗の叔父・留守政景は城に追い詰められて苦戦を強いられた。のちに政宗の母・義姫（義光の妹）の仲介によって和睦に至るまでの、緊迫の包囲戦を模式化した一戦。
