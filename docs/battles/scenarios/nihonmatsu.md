# 二本松攻め

## 基本情報

- **年月日**: 天正13〜14年（1585〜1586年）
- **場所**: 陸奥国・安達郡 二本松城（地形はゲーム用の模式図・創作）
- **両軍と兵力**: 伊達軍（政宗・成実・政景ら） 対 二本松・畠山勢（畠山義継と城兵）
- **勝利条件**: 畠山義継の撃破、または二本松城本丸の制圧（敵全滅でも勝利）
- **敗北条件**: 伊達政宗の討ち死に、または制限ターン（10ターン）超過
- **該当章**: [『伊達の国』第7章「摺上原と人取橋」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-ch07-aizu-shigezane)
- **開戦メッセージ**: 天正13〜14年・二本松攻め。父・輝宗の仇を討つべく、丘上の二本松城を攻略せよ。

## 概況

人取橋の戦いの発端となった父・伊達輝宗の死（二本松義継による連れ去り事件）の報復として、伊達政宗は二本松城を包囲した。険しい丘上に築かれた二本松城は容易に落ちず、包囲は年を越えて長期に及んだ。孤立した城内ではやがて抗戦の限界が訪れ、天正14年（1586年）に義継は家臣に討たれ、二本松城は開城に至った。
