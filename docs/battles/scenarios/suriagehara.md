# 摺上原の戦い

## 基本情報

- **年月日**: 天正17年6月5日（1589年）
- **場所**: 陸奥国・耶麻郡 磐梯山麓・摺上原（地形はゲーム用の模式図・創作）
- **両軍と兵力**: 伊達 約2万3千（伝承値） 対 蘆名 約1万6千（伝承値・佐竹援軍含む）
- **勝利条件**: 敵総大将・蘆名義広の撃破、または蘆名・佐竹軍の全滅
- **敗北条件**: 伊達政宗の討ち死に（または10ターン超過）
- **該当章**: [『伊達の国』第7章「摺上原と人取橋」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-ch07-aizu-shigezane)
- **開戦メッセージ**: 天正17年・摺上原の戦い。磐梯山麓の側面から突き、蘆名義広を打ち破れ。

## 概況

蘆名の重臣・猪苗代盛国が伊達に内応し、猪苗代城が前線基地となった。伊達軍は先手・猪苗代盛国、二番・片倉景綱、三番・伊達成実、四番・白石宗実、五番旗本・伊達政宗の陣立てで摺上原へ布陣。西風に乗った蘆名勢に序盤は押し込まれるも、成実と宗実が磐梯山麓を回り込んで側撃し、東風への風向き変化とともに形勢が逆転した。金上盛備・佐瀬種常らが踏みとどまる中、蘆名勢は日橋川へと総崩れとなり、会津の覇権が伊達へ移った。
