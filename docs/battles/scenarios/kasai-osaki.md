# 葛西・大崎一揆

## 基本情報

- **年月日**: 天正18〜19年（1590〜1591年）
- **場所**: 陸奥国・旧葛西大崎領（岩手沢方面の城砦／地形はゲーム用の模式図・創作）
- **両軍と兵力**: 伊達鎮圧軍（模式編成） 対 旧葛西・大崎領一揆勢（模式編成）
- **勝利条件**: 一揆勢・本隊（大将）の撃破、または一揆勢の全滅
- **敗北条件**: 伊達政宗の討ち死に（または10ターン超過）
- **該当章**: [『伊達の国』第8章「束の間の領国」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-ch08-aizu-ryokoku)
- **開戦メッセージ**: 天正18〜19年・葛西大崎一揆。城砦に立て籠もる一揆勢を鎮圧し、政宗への嫌疑を晴れ。

## 概況

豊臣秀吉の奥州仕置によって改易された旧葛西・大崎領で大規模な一揆が勃発した。伊達政宗には一揆を陰で扇動したという嫌疑がかけられ、家の存続を懸けて自ら鎮圧に出陣することとなる。大崎氏の旧家臣・氏家氏の城であった岩手沢城（のちの岩出山城）周辺も一揆の戦火で荒れ果てた。鎮圧ののち、政宗は先祖代々の米沢・伊達郡を失い、この旧葛西・大崎領へ移封されることになる。
