# 長谷堂の戦い

## 基本情報

- **年月日**: 慶長5年9月（1600年）
- **場所**: 出羽国・村山郡 長谷堂城（地形はゲーム用の模式図・創作）
- **両軍と兵力**: 最上義光・鮭延秀綱＋伊達援軍（留守政景3千） 対 上杉軍（直江兼続ら約2万・伝え）
- **勝利条件**: 直江兼続の撃破、または8ターン終了まで長谷堂城本丸を守り切る（敵全滅でも勝利）
- **敗北条件**: 長谷堂城本丸の制圧、または最上義光の討ち死に
- **該当章**: [『伊達の国』第3章「松川の戦い」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-ch03-matsukawa)
- **開戦メッセージ**: 慶長5年・長谷堂の戦い（番外編）。直江兼続の猛攻から本丸を守り抜き、伊達援軍の到着を待て。

## 概況

関ヶ原の戦いと同時期に繰り広げられた出羽の決戦。上杉家の執政・直江兼続が大軍を率いて最上領へ侵攻し、鮭延秀綱の守る長谷堂城を包囲した。最上義光が救援に動き、伊達政宗からも叔父・留守政景率いる3千の援軍が東から駆けつけた。激戦のさなか、関ヶ原での西軍敗北の報が届き、上杉軍は撤退を決断した。政宗本人の合戦ではないため「番外編」として収録する。
