# 人取橋の合戦

## 基本情報

- **年月日**: 天正13年11月17日（1585年）
- **場所**: 安達郡・本宮市青田字茂庭（地形はゲーム用の模式図・創作）
- **両軍と兵力**: 伊達 約7千（伝承値） 対 南奥州諸侯連合 約3万（伝承値）
- **勝利条件**: 政宗が北端の離脱マス（小浜方面）へ到達、または6ターン終了まで生存
- **敗北条件**: 伊達政宗の討ち死に
- **該当章**: [『伊達の国』第7章「摺上原と人取橋」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-ch07-aizu-shigezane)
- **開戦メッセージ**: 天正13年・人取橋の合戦。政宗を北端の小浜方面へ逃がせ。

## 概況

父・伊達輝宗を二本松で失った若き当主・伊達政宗（19歳）は、小浜城を足場に二本松へ出陣。しかし佐竹義重率いる南奥州連合の大軍に押され、阿武隈川・人取橋のほとりで最大の危機を迎える。73歳の老将・鬼庭良直（左月斎）が橋の南詰めで殿（しんがり）を務め、伊達成実（18歳）が踏みとどまる間に、政宗は北の小浜方面へ退路を開く。
