# 須賀川攻め

## 基本情報

- **年月日**: 天正17年10月（1589年）
- **場所**: 陸奥国・岩瀬郡 須賀川城（地形はゲーム用の模式図・創作）
- **両軍と兵力**: 伊達軍（政宗・成実・景綱ら） 対 二階堂氏家臣団（模式編成）
- **勝利条件**: 二階堂守備隊・本隊の撃破、または須賀川城本丸の制圧（敵全滅でも勝利）
- **敗北条件**: 伊達政宗の討ち死に、または制限ターン（10ターン）超過
- **該当章**: [『伊達の国』第7章「摺上原と人取橋」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-ch07-aizu-shigezane)
- **開戦メッセージ**: 天正17年・須賀川攻め。阿武隈川の渡河点を押し渡り、丘上の須賀川城を攻略せよ。

## 概況

摺上原の戦いで蘆名氏を破った伊達政宗は、会津領の南の押さえとしてなお抵抗を続けていた岩瀬郡の須賀川城へ兵を進めた。前年に当主・二階堂盛義を失った二階堂氏は家臣団が城を守って抗戦したものの、伊達軍の猛攻の前に落城。名族・二階堂氏はここに滅亡し、会津と中通り南部は伊達の勢力下に入った。
