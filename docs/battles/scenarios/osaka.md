# 大坂の陣

## 基本情報

- **年月日**: 慶長19〜20年（1614〜1615年）
- **場所**: 摂津・河内方面（大坂城外郭の街道／地形はゲーム用の模式図・創作）
- **両軍と兵力**: 仙台藩伊達軍（政宗・嫡男秀宗従軍） 対 豊臣方・大坂勢（模式編成）
- **勝利条件**: 豊臣方・前線本隊（大将）の撃破、または豊臣方・大坂勢の全滅
- **敗北条件**: 伊達政宗の討ち死に（または10ターン超過）
- **該当章**: [『伊達の国』コラム「宇和島 ― 飛び地の番外編」](https://oosawak.github.io/date-no-kuni/index.html#/post/date/book-col-uwajima)
- **開戦メッセージ**: 慶長19〜20年・大坂の陣。政宗と嫡男・秀宗、戦国最後の大戦で伊達の旗を示せ。

## 概況

徳川家康が大坂の豊臣方を攻め、諸大名に参陣を命じた戦国最後の大戦。47歳の伊達政宗は、長男・伊達秀宗を伴って仙台藩の軍勢を率い参陣した。ここでの従軍と働きによって、戦後の1615年に秀宗は伊予宇和島10万石を与えられ、仙台本家と並ぶ分家・宇和島伊達家の初代藩主となる。徳川の世に伊達の名と家の位置を刻み込んだ、政宗最後の戦場を模式化した一戦。
